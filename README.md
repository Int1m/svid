# Наше свидание

Одностраничный сайт-приглашение: убегающая кнопка «Нет», выбор даты, кино / бильярд / ужин / «всё сразу» и итоговая карточка с деталями.

## Запуск

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 7100
```

Сборка: `npm run build`, результат — в `dist/`.

## Почта

В `src/config.ts` укажи свой адрес в `OWNER_EMAIL`. На итоговом экране кнопка «Отправить выбор» передаёт детали через FormSubmit. При первой отправке сервис может прислать на указанную почту письмо для активации формы — его нужно подтвердить один раз. Без адреса остаётся кнопка, открывающая почтовое приложение с готовым текстом.

## Данные

- Сеансы «Сумерки. Сага. Затмение» сохранены в `src/karo-schedule.json` с официального сайта КАРО для 19–25 ноября 2026. На другие даты сайт предлагает открыть актуальное расписание КАРО.
- Бильярд: «Омерзительная 8», Пятницкая ул., 82/34с1.
- Ужин: Rusty Rat & Pizza, Большой Черкасский пер., 13с4.

Технологии: React, TypeScript, Vite, Lucide. Состояние последнего выбора сохраняется локально в браузере.
